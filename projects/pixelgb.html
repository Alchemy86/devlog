PixelGB

High-quality pictures extracted from a Game Boy cartridge and checked against the console that drew them. Not reconstructed from a disassembly — photographed. PixelGB puts the cartridge in a cycle-accurate emulator, walks the game to each of its 226 maps, and lets the game load its own tileset, apply its own palette and draw its own screen. Then it renders the same map a second time from the data and compares the two, pixel for pixel.

What it is

Every published Kanto map you have seen exists because the world was being rebuilt from the outside, by something that is not the game. PixelGB is not outside — it is holding the console. It plays the opening, saves the machine's state the moment it stands on a real map, and for each of the 226 maps rewinds to that moment, points a warp at the target and walks the player in. Everything after that is the game's own: the map header, the tileset copy into video RAM, the palette, the objects, the screen. The palette is learned, not asserted; and PixelGB cannot invent detail and does not try — there is no upscaler and no "enhancement."

The addresses it uses to do this all come from AtlasGB's evidenced Pokémon Red/Blue atlas, and the console it holds is TerminalGB — pixel-exact on dmg-acid2, 0 of 23,040 pixels different. They are siblings.

How a picture is proved

A rendered map is not trusted because it looks right. Each one passes four checks, in increasing order of proof — the last of which is a literal pixel-for-pixel comparison of what the hardware drew:

  1. The header — the engine-loaded map header against the one PixelGB read from the same bytes. 226 of 226 agree.
  2. The art — the tileset graphics the game copied into video RAM, against the same graphics in the cartridge.
  3. The blocks — the engine's live overworld map, against the cartridge's block list. 204 identical, 22 changed by a map script.
  4. The pixels — the 160×144 the PPU actually drew, against the same window composed from the map data, pixel for pixel. 212 exact, 3 explained by a script, 11 unresolved and named.

Alignment is searched, not assumed, and the excluded pixels — those an object may have covered, and those outside the map proper — are recorded rather than quietly dropped.

What it does not claim

PixelGB ships no cartridge and no cartridge data. The eleven maps it could not verify are named, not rounded away: ten have no reachable arrival point, so the camera lands outside the map proper, and one is the Hall of Fame, where a script cannot be dismissed. The published set is four-shade only — the Game Boy Color path was never exercised end to end, because no Color boot ROM was available — and Super Game Boy per-area colour is a documented non-goal. All the verification numbers are from a single Pokémon Blue cartridge; Red is supported but unmeasured.

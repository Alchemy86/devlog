AtlasGB

Memory maps for Game Boy cartridges where every claim carries the evidence for it. Most memory maps are transcriptions — somebody read an address once and everybody since has copied it, with no way to tell a right address from a plausible one. AtlasGB records how each entry was checked, and the entries with no evidence say so, rather than borrowing confidence from the rows beside them.

First atlas: every address in Pokémon Red and Blue.

What it is

One atlas per cartridge. Each entry names an address, what lives there, and — for almost all of them — the evidence that the cartridge was watched using it. The evidence itself is produced by a cycle-accurate emulator (TerminalGB) that runs the real cartridge and records what it does. A description is written only where that watching produced something specific and unambiguous; where it did not, the entry stays blank and is counted, because a plausible sentence guessed from a symbol name is exactly the thing this project exists as a reaction to.

How a claim earns its place

Every entry records its own evidence tier. The tier is not editable by hand — it is written only by landing a verification report produced by running the cartridge, and CI recomputes a SHA-256 digest of the column so that editing a token by hand, or adding an address without re-running the check, turns the build red. A tier in the published atlas therefore always names a real run against a real cartridge.

Tier Meaning How it is proved
RROMThe address appears in the ROM image as the operand of a load instruction — a byte scan recording a count.
LLiveThe byte changed while the cartridge ran a fixed button script on a cycle-accurate emulator, from cold boot.
IInvariantA named, hand-written check proved the entry means what it says — not merely that it exists.
·NoneNo evidence yet. Stated openly, not hidden — seven storage entries currently sit here.

Milestones

25 Aug 2026

Re-verified against a second cartridge boot

The atlas was re-produced from scratch against a second, independent boot of a retail Pokémon Blue cartridge and save, run twice for determinism. Both runs were byte-identical and agreed with the earlier run: zero entries moved tier, and the atlas's 2,898 claims disagree with the cartridge in zero places.

25 Aug 2026

Descriptions written by watching, not guessing

136 descriptions were generated by stepping a real playthrough frame by frame — recording which bytes change, and the code behind every write — rather than by searching for a plausible label. A forced gym battle against Misty was set up, checked, and only then trusted.

17 Aug 2026

Findings from the cartridge campaign land

The entries the cartridge campaign established were described and linked back to the findings behind them, so the front page points at the evidence rather than at assertions.

15 Aug 2026

First atlas, standing on its own evidence

Pokémon Red and Blue published as the first atlas — one directory per cartridge, work RAM and high RAM fully accounted for with no holes, evidence tiers assigned by a real run against the cartridge from the start.
